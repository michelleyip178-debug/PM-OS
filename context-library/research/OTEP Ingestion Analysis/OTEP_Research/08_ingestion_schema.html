BO decisions that gate this schema

D1 TC rule for agilePSD & Other (TBC)

Is time commitment required for uncertain-type gigs? Affects 109 gigs.

Schema impact: If yes — 109 more gigs become hard-blocked. If no — TC validation rule is marked N/A for these types. The matrix cell changes from TBC → REQ or —.

D2 Start date exemptions

Are evergreen/standing opportunities (e.g. Secondments, permanent roles) exempt from requiring a start date?

Schema impact: If Secondments exempt — 200 gigs unblock immediately. The PEND cell for Secondment in the matrix changes to —. Would require a new is_evergreen flag or type-level override in the schema.

D3 Stale gig handling

Should Open gigs with end_date in the past be ingested, skipped, or flagged?

Schema impact: Affects exclusion rule #3. If skipped — ingestion shrinks by up to 346 gigs. If flagged with status — OTEP schema needs an is_stale or listing_status field. If ingested as-is — no schema change needed.

D4 No-tag gig handling

Hard block, ingest as "Uncategorised", or attempt fuzzy type inference for 78 untagged gigs?

Schema impact: If Uncategorised allowed — OTEP type enum must include an "Uncategorised" value. If fuzzy inference — classification logic gains a fallback branch (keyword matching on GigName body). If hard block — no schema change.

Known gaps in the current OTG data model

Gap Root cause in OTG Recommended fix Owner
No dedicated type column Opportunity type embedded in GigName as [prefix] convention Add a Type field to OTG creation form. Short-term: maintain regex classification; long-term: replace with form-enforced enum. OTG platform owner
No tag governance Any agency can create a novel [prefix] — no canonical list enforced at source Define and publish a canonical tag taxonomy. Gate new tags at OTG creation. Assign a tag registry owner to approve additions. Policy / OTG admin
Eligibility misused as type [Female Only], [For Grade 12/11 equivalent] used as type tags instead of a separate eligibility field Add a separate Eligibility field to OTG. These entries currently cannot be typed correctly — they have no opportunity type, only a filter condition. OTG platform owner
No staleness management Status stays "Open" even after end_date passes — no auto-close logic in OTG OTG should auto-delist or set Status = "Closed" when end_date passes. OTEP ingestion is the wrong place to make this judgment call at scale. OTG platform owner
Casing inconsistency [Innofest] vs [INNOFEST] produce different classification results Ingestion pipeline normalises all tags to lowercase before regex matching (already implemented). Long-term: OTG enforces canonical casing at source. Ingestion pipeline (done)
