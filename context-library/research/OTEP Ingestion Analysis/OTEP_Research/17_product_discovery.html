1. The Problem

CareerCompass promises officers a single place to discover all development opportunities. The OTG ingestion pipeline is what makes that real for 160,000 officers on the platform today.

The current state: the pipeline exists, but 75% of OTG's open gigs won't pass it. Officers searching for secondments will see almost nothing. Some filter views will return single digits. This isn't a technical failure — the pipeline is doing exactly what we designed it to do. The problem is that the rules were set before we ran against real data.

Risk
Officers try CareerCompass once, find it sparse compared to what they know is in OTG, and stop returning. Early word-of-mouth kills adoption before the platform has a chance to build traction.

3. Decisions — Confirmed & Pending

All v3 rules now ratified. I-017 and I-018 confirmed by Xian Zhang 15 Jun 2026.

✓
I-015 — Start date optional for Job & Secondment
Confirmed 12 Jun · Unlocked ~200 Secondments and ~61 Jobs

Secondments are standing roles — start date genuinely may not exist. Jobs similarly. Gig/STIP remain required (time-bound roles). PSFG: required. This matches option B from the original proposal.

Decision: I-015 ratified  ·  Update OTEP-192 ACs before S5 grooming

✓
I-014 — Function optional for all types (display-only)
Confirmed 12 Jun · Unlocked 174 gigs

Function is display-only on the listing card — a gig without a function is still a valid opportunity. Gigs missing function won't appear in function-filtered views, which is acceptable. Amber to design the null state for the listing card.

Decision: I-014 ratified

✓
I-013 — Time commitment required for Gig/STIP only
Confirmed 12 Jun · agilePSD now classified as PSFG (TC not required)

TC is not required for Job, Secondment, SJR, or PSFG (formerly agilePSD). Only Gig and STIP require it. This closes the "agilePSD TBC" uncertainty.

Decision: I-013 ratified

✓
I-004 — Lifecycle rule confirmed: closing_date > today OR NULL
Confirmed · Stale gigs ingest but are hidden by lifecycle rule

Stale gigs ingest into the DB but are never visible to officers. The lifecycle rule handles this at display time. No pipeline exclusion needed for MVP. Test entry exclusions (GigIDs 13733, 14807, 14813) confirmed.

Decision: I-004 confirmed

I-017 — Secondment maps to JOB category in CareerCompass
Confirmed by Xian Zhang 15 Jun 2026  ·  259 Secondments ingest as Jobs

Proposed mapping: Secondment opportunities display under the "Jobs" category in CC (alongside permanent Jobs). This is a CC UX decision, not an ingestion rule. The 127 Secondments that pass v3 field rules can ingest regardless — I-017 only affects the display category in CC.

Confirmed: Xian Zhang 15 June 2026
