1. The Problem

CareerCompass promises officers a single place to discover all development opportunities. The OTG ingestion pipeline is what makes that real for 160,000 officers on the platform today.

The current state: the pipeline exists, but 75% of OTG's open gigs won't pass it. Officers searching for secondments will see almost nothing. Some filter views will return single digits. This isn't a technical failure — the pipeline is doing exactly what we designed it to do. The problem is that the rules were set before we ran against real data.

Risk
Officers try CareerCompass once, find it sparse compared to what they know is in OTG, and stop returning. Early word-of-mouth kills adoption before the platform has a chance to build traction.

3. Open Decisions

These are unresolved. Each one directly affects catalogue size or story ACs. They need owners and deadlines.

A
Is start date (GigStart) required or optional?
Affects 288 gigs — the single biggest lever

Secondments are standing roles. A start date may genuinely not exist for them. Gigs and STIPs are time-bound — the date is material to the officer's decision.

Options
A
Required for all types
288 gigs hard-skip. Blanket rule hits standing roles unfairly.
B
Optional for Secondments + Jobs only (recommended)
Most of 288 pass. Matches role semantics — standing roles don't have a fixed start.
C
Remove as required field entirely
Maximum unlock, but reduces listing quality for time-bound roles.

Owner: Pow Hwee + Michelle  ·  Needed by: before OTEP-192 ACs finalised

B
Is function required or display-only?
Affects 174 gigs, heavily overlapping with Secondments

Function drives the filter on OTEP-86. If required, 174 gigs hard-skip but filter accuracy is preserved. If optional, those gigs appear in unfiltered browsing but not in function-filtered views.

Options
A
Required for all types
174 gigs hard-skip. Filter is accurate but smaller.
B
Optional / display-only (recommended)
174 gigs pass. A gig without a function is still a valid opportunity — it just won't appear in function-filtered views.
Design note for Amber
If function is optional, the listing card needs a graceful null state. Empty function-filter results need a design too.

Owner: Pow Hwee + Michelle  ·  Needed by: before OTEP-192 ACs finalised

C
Are competencies + time commitment required or optional?
Affects OTEP-87 detail page design and Léo's transform logic

If required: every ingested record has competency data — Amber designs for a populated section. If optional: records can be null — Amber designs both states (populated and empty). Open item #41: Pow Hwee to schedule meeting with core team.

Owner: Pow Hwee (to schedule) + Michelle  ·  Needed by: before S4/S5 OTEP-87 grooming

D
Stale gig policy — pipeline exclusion or rely on lifecycle rule?
Affects 346 open gigs past their closing date

The existing lifecycle rule (closing_date > today OR closing_date IS NULL) already hides stale gigs from officers. This is a DB hygiene question, not an officer experience question.

Options
A
Rely on lifecycle rule for MVP (recommended)
Stale gigs ingest, sit in DB, never visible to officers. Already works correctly.
B
Pipeline exclusion (stale + zero applicants)
255 fewer DB records. Cleaner audit trail. Add in S5/6 review.
Also needed
Hardcode exclusion of 3 test entries (GigIDs 13733, 14807, 14813) from ingestion. Michelle to add to OTEP-192 ACs.

Owner: Pow Hwee + Michelle  ·  Needed by: before OTEP-192 closes

E
Programme-type TC exemption (agilePSD, KidSTART, etc.)
Affects ~109 gigs in edge-case programme categories

agilePSD (29 gigs, all from PSD) is the cleanest case — fully dated, zero stale. Are programme types exempt from the time commitment requirement like Jobs and Secondments, or must they have TC like Gigs?

Owner: Michelle → BOs (Jacky / Xian Zhang)  ·  Needed by: before go-live date is set

F
What is the minimum viable catalogue threshold for launch?
No floor set = no go-live date can be confirmed

Recommended: 350+ ingested gigs with at least 3 opportunity types with 20+ each. Below 300 is thin — some filter views will return single digits.

Owner: Michelle → BOs  ·  Needed by: before S5 planning
