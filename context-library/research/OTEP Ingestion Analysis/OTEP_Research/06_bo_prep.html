What is happening

OTEP imports opportunities from the OTG system. For an opportunity to appear on the platform, it needs a complete set of information — things like a start date, a function, and a clearly labelled opportunity type. If any of these are missing, the opportunity is blocked from appearing.

We've run that check across all 633 open opportunities in the system. The results show a significant data quality gap — not because agencies have been careless, but because the OTG system has never enforced these requirements at the point of creation. Agencies posted opportunities the way the system allowed them to, and now we're asking OTEP to work with that data.

What was decided on 12 June (v3 rules — locked)

✓
I-015 — Start date is now optional for Jobs and Secondments
Unlocked: 255 records · Ratified 12 Jun 2026
What was decided. For Job and Secondment types, a missing start date is valid. These are standing roles — there is often no fixed start date by design. The listing card shows "Ongoing / No fixed start" instead of a blank field. Start date remains required for Gigs and STIPs.
Impact. The single largest unlock. 230 Secondments and 87 Jobs at Enterprise Singapore and MTI were blocked on this field alone. All are now passing.
✓
I-014 — Function is now optional for all opportunity types
Contributed to ESG and NLB unlocks · Ratified 12 Jun 2026
What was decided. Function is display-only. A record without it still ingests. Officers browsing without a function filter see it; function-filtered views correctly exclude it. Amber (designer) will handle the graceful null state — no "Function: —" label shown on cards.
✓
I-013 — Time commitment required for Gigs and STIPs only
Unlocked 5 misclassified records · Ratified 12 Jun 2026
What was decided. Time commitment (hours per week, start/end dates) is required only for Gig and STIP types. Jobs and Secondments are full-time roles — the concept does not apply. Five records that were blocked because a Job lacked a TC field now pass.

Both decisions confirmed — Xian Zhang 15 Jun 2026

✓
I-018 — 5-category model confirmed: STIPs, Gigs, PSFG, Jobs, SJR
Confirmed 15 Jun 2026 · Xian Zhang / Michelle · Gates: OTEP-86, OTEP-289
Confirmed. The canonical 5-category model for CareerCompass is STIPs, Gigs, PSFG, Jobs, SJR. PSFG replaces agilePSD. Jobs includes Secondments (I-017). SJR is in the model but excluded from MVP ingestion (I-009). This is the taxonomy for OTEP-86 filter logic and all display labelling.
✓ Confirmed 15 Jun 2026. Engineering can finalise OTEP-86 filter logic using this taxonomy.
✓
I-017 — Secondment = Jobs confirmed: same rules, same category
Confirmed 15 Jun 2026 · Xian Zhang / Michelle · Gates: card labelling, filter keys
Confirmed. Secondment falls under the Jobs category in CareerCompass and is treated identically for all ingestion and product rules. No separate Secondment type in the 5-category model. Officers see Secondments in the Jobs filter.
✓ Confirmed 15 Jun 2026. Secondments display as Jobs. No separate type branching required.
