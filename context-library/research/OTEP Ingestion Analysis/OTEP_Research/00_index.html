4 decisions needed from Business Owners

D1 Time commitment for uncertain types Open

Is time commitment required for agilePSD and Other tagged gigs? These 109 gigs sit in limbo — their TC rule is unconfirmed.

A ★ Treat like Secondment/Job — time commitment not required. 29 agilePSD gigs unblock immediately (minus 5 with missing Function).
B Require time commitment — 109 more gigs become hard-blocked and go into the remediation report.
At stake: Up to 80 additional gigs passing ingestion if Option A is chosen.
See rule R11 in Ingestion Rules →
D2 Start date exemptions for Secondments Open

Start date is the single biggest blocker: 288 gigs are missing it, 200 of which are Secondments. Are standing/evergreen secondments exempt from needing a start date?

A ★ Secondments (and permanent Jobs) are exempt — start date optional for these types. Up to 200 Secondments unblock.
B Start date required for all — no exceptions. 288 gigs remain blocked until agencies fill it in.
At stake: The largest single unlock. Option A could unblock ~200 Secondments alone.
See Secondment breakdown in DQ by Type →
D3 Stale gig policy Open

346 open gigs have passed their end date — 74 by more than a year. 255 of these have zero applicants. Should these appear on OTEP?

A ★ Exclude stale gigs with zero applicants (255). Live stale gigs with applicants (91) still pass — someone is interested.
B Exclude all stale gigs (346). Cleanest catalogue but removes some active-interest listings.
C Ingest all as-is. Applicants may apply to roles that no longer exist.
At stake: Applicant trust. Stale listings with no owner erode confidence in the platform.
See staleness data in Summary Dashboard →
D4 Gigs with no type tag Open

78 gigs have no [type prefix] in their name. Without a type, OTEP cannot classify or validate them. Most appear to be Jobs from MSF and Enterprise Singapore.

A ★ Hard block — route to remediation report. Agencies must add a prefix before next ingestion run. Simple and enforceable.
B Ingest as "Uncategorised" — visible on OTEP but not type-filtered. Risks permanent orphan listings.
At stake: Tag discipline going forward. Without enforcement, new untyped gigs will appear every ingestion run.
See unrecognised type deep-dive →
