# CareerCompass Job Category Filter — Decisions Resolved ✅

## Context

CareerCompass will let officers filter opportunities by job category. We're using the 29-category WOG taxonomy as the standard label set — so whether an opportunity comes from Careers@Gov or OTG, officers see the same familiar filter labels.

We've mapped all Careers@Gov and OTG categories to WOG. Most are straightforward. A few have more than one reasonable home and we need your call before we lock the mapping in.
