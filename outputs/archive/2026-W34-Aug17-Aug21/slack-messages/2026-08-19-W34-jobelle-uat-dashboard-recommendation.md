2. **Show how much of the full test plan is done** — right now the pie chart only shows the status of tickets already logged. It'd help to see "X out of Y planned tests done" so we know if we're looking at the whole picture or just part of it.

3. **Mark which results used real-looking data** — since some testing is on scrambled data, it'd help to flag which passes we can fully trust versus which ones might need a second look later.

4. **Show progress over time, not just today** — right now every gadget only shows "today." A simple chart showing progress over time would make it easier to tell if we're on track, without checking day by day.
