Decision-by-Decision Impact

1. Secondments → "Jobs" category; StartDate now optional for Jobs
Secondments are standing roles — no fixed start by nature. New rule: start date optional for Jobs (includes Secondments + internal jobs). Primary driver of the +265 unlock.
+190
2. Internal Jobs ("Job" type) — StartDate optional
87 blocked Jobs in original data. Start date was the primary blocker for ~40. Remainder (47) blocked by other issues (Function, BusinessUnit, TypeTag).
+40
3. Function field → optional (display-only, not required for ingestion)
174 records were blocked by Function. Most overlap with StartDate blocks (already counted above). These are the additional pure-Function-only blocks across Jobs, Gigs, STIPs.
+30
4. TimeCommitment required for STIPs & Gigs only (not Jobs/Secondments)
5 records were blocked solely by missing TimeCommitment. These are Jobs/Secondments that lacked TC — now they're exempt. STIPs & Gigs still require start/end date + hours-per-week.
+5
5. "No tag" / "Other (TBC)" / "agilePSD" records — still blocked
78 + 56 + 29 = 163 records need valid type prefix at source. PM decisions can't resolve these. Remediation: DevOps + agencies fix OTG type tags before go-live.
0
6. 5-category model (STIPs / Gigs / Jobs / SJR / PSFG) — pending validation
New taxonomy supersedes "Internal Job / STIPs & Gigs / SJR." The category model itself doesn't change the pass count above — it changes how records are labelled after ingestion. Pending: Xian Zhang team validation by w/c 15 Jun.
—
7. C@G as source-of-truth dedup rule (where a job is in both OTG and C@G)
New dedup rule — prefer Careers@GovTech over OTG copy where duplicated. Not yet decided: blocked on ESG HR confirmation. Don't build yet (Léo: see handoff doc).
