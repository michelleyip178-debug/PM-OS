## Proposed North Star (New — to be confirmed today)

> **By Dec '28: 50% of onboarded officers complete at least one development action — course completion or opportunity placement — originating from CareerCompass, tracked on a rolling 12-month basis.**

**Why this definition matters:**
- Counts *completion*, not enrollment, application, or login
- "Attributable to CareerCompass" means the action must originate from the platform
- Browsing, enrolling, and applying alone do not qualify

**Progressive targets:**

| Milestone | Target | Context |

| Dec '26 (MVP) | Baseline | Pilot cohort only — establish measurement |
| Mar '27 (R1) | 10% | Early adoption phase |
| Dec '27 (R4) | 30% | Advanced features live |
| Dec '28 (R8) | 50% | Full AI-powered maturity |

## Release Scope — What's In Each Release

### MVP (Oct '26) — "See All Opportunities"
*One place to discover opportunities, reducing friction across portals.*
- Auto-generated Talent Profile (HR integration) + competencies
- Unified Hub: STIPs, GIGs, SJRs, Internal jobs, C@G jobs
- Competency Gap analysis
- Courses: personalised recommendations + keyword search
- Competency Inference (Phase 1) from CVs
- Baseline product analytics

### Release 1 (Jan '27) — "Seamless Application" *(REVISED)*
*Click-Apply-Track. Frictionless action on career opportunities.*

**In scope (revised):**
- Streamlined Apps: pre-filled applications for STIPs, GIGs, SJR, C@G, Internal jobs + post jobs on ATS
- Status Tracking: end-to-end application monitoring (ATS integration)
- Application within CareerCompass: no redirects
- Saved Jobs: resume application of target jobs quickly
- External-facing Profile page: officer profile accessible during application (read-only)

**Deprioritised from original R1:**
- Smart Assistant (auto-populates strengths/experience)
- Gap Radar (insights for specific target roles)
- Intelligence Dashboard (usage pattern tracking)

### Release 2 (Q2 '27) — "Purpose-Driven Growth" *(REVISED)*
*Align learning and development with real career goals.*

**In scope (revised):**
- Competency Learning: course recommendations by competency gap, factoring learner history across all LMS
- HRPS Courses: bring in courses through course aggregator
- Learner History: consolidated across all LMS
- Jobs related to target roles: highlight available jobs related to target role
- Competency Proficiency Levelling: allow officers to set their own proficiency levels

**Deprioritised from original R2:**
- Aspiration Tracking (declare future career goals)
- Smart Planner (template-based development plans)
- HR Portal (visibility into officer career activity)

### Release 3 (Q3 '27) — "Build Plans Together"
- Supervisor Alignment: shared visibility of development plans
- Enhanced Gap Analysis: deep-dive role comparisons
- Structured Support: supervisors guide growth efforts
- Collaborative Planning: interactive development templates
- Activity Tracking: HR monitors agency engagement

## Anticipated Pushback

### Most Likely

**HR Portal cut from R2 — Xian Zhang almost certainly raises this**
The prep doc already flags it. HR Portal is agency-side visibility into officer activity. As a BO with accountability for her officers' development, deferring it to R3 (Sep '27) or later means no agency-facing visibility for over a year post-launch. Expect: "How do I know if officers are actually using this?"
- *Positioning:* Baseline product analytics at MVP gives the team data. Agency-facing dashboards follow once the data layer is stable. R3 targets 60% of agencies actively using analytics — frame it as phased, not cut.

**Smart Assistant cut from R1 contradicts the R1 theme**
R1 is called "Seamless Application." Smart Assistant (auto-populates strengths/experience) is the most literal interpretation of seamless. Cutting it while keeping the theme name invites: "What makes this seamless if officers still fill in their applications manually?"
- *Positioning:* Pre-filled applications using existing profile data (Streamlined Apps) covers the core friction. Smart Assistant requires more AI build — deferring it protects the October date without compromising the core apply flow.

**North Star attribution — "what counts as originating from CareerCompass?"**
The definition is tight: completion must *originate* from the platform. Edge case likely raised: if an officer discovers a course on CareerCompass but registers directly on LEARN, does it count? This is both a measurement question and a scoping question.
- *Watch for:* If no one has an answer on measurement, the baseline-at-MVP approach becomes the necessary safety valve. Note any clarification Adrian gives verbally.

**60k LEARN courses — "X%" still blank**
You cannot present an OKR with a TBD target. BOs will ask for the number. Either Adrian proposes one on the spot, or it surfaces as an unresolved OKR leaving the meeting.
